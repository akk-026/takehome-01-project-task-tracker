# Northstar Project Tracker

An incremental rebuild of the project and task tracking assignment. Each feature is implemented in
its own focused commit so the history explains how the system was assembled.

## Development

Requires Node 20 or later. The initial commit contains only the clean application structure; each
subsequent commit adds one working capability.

```sh
npm start
```

## Planned delivery order

1. Application shell and persisted datastore
2. Authentication and server-side role checks
3. Project management and membership
4. Task creation, editing and assignment
5. Lifecycle and dependency rules
6. Search, filters, pagination, bulk actions and CSV export
7. Dashboard, history and overdue alerts
8. Board interface, tests and documentation
